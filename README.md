# toDoList (PHP)

A CRUD task list built with PHP and MySQL — the first project written
while learning PHP. Create a task, read the list, update an entry,
delete it.

## Stack

- PHP for the request handling and page rendering
- MySQL for storage

## Running it

Point a PHP-capable server (XAMPP, or `php -S`) at the project folder
and create the database the scripts expect, then open the site in a
browser.

```bash
php -S localhost:8000
```

## Why it's here

Kept as a record of where the PHP work started. The patterns are
deliberately simple — no framework, no ORM, just queries and includes.
